1. **Agente MD:** archivo `AGENTE-COPILOT-PORTAFOLIO.md` en la raíz.
2. **Portafolio basado en iPortfolio:** aplicación Angular 22 (componentes standalone, SCSS y JSON). Se tomó el diseño de referencia del sidebar oscuro, imagen circular y hero.

- **0:45–1:00:** filtrar proyectos por Web/IoT/Redes y abrir una tarjeta de detalle.

## Cómo grabar en Windows

1. Abre VS Code y el navegador mostrando tu portafolio.
2. Pulsa `Win + G` y graba con Xbox Game Bar si funciona en tu equipo, o usa OBS Studio.
3. Graba pantalla, recorre el proyecto y guarda el archivo MP4.
4. Si el portal pide un video además del ZIP, súbelo por separado.
